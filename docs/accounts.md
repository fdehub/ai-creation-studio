# ChatGPT 与 Muse 账号接入

账号接入始于 0.2.0；本文更新于 2026-11-03。

入口：**策略与设置 → AI 引擎策略 → 平台账号登录**。登录与 API Key 配置并列；本机 `.env` 保持私有，历史测试中的硬编码凭据已改为环境变量读取。账号模型可绑定全部 Agent，或分别绑定写作编辑、人物情节与世界观。

## 使用前更新

```powershell
.venv\Scripts\python -m pip install -r backend\requirements.txt
npm ci
```

重启后端并刷新前端。Windows 默认使用独立的系统 Edge 实例；其他环境可执行 `npx playwright install chromium`。如需指定系统浏览器，可设置 `NOVEL_MUSE_BROWSER_CHANNEL=chrome` 或 `msedge`。Node.js 24+ 是 Muse 浏览器适配器的运行依赖。

## ChatGPT：官方 OAuth

1. 点击 **Continue with ChatGPT**。
2. 在打开的 OpenAI 官方页面选择账号，并授权该应用使用模型。
3. 返回工作台，读取该账号的可用模型。
4. 选择模型与绑定范围，点击“绑定到所选 Agent”。之后正常进入编辑器或大纲生成即可。

实现采用 OpenAI 面向开源客户端的动态注册流程：首次使用 `dynamic_agent_client`，回调后保存平台实际颁发的 client ID，后续重新登录复用该注册。每次生成独立 state、OIDC nonce 和 PKCE S256 参数；授权码只使用一次。

后端校验 ID token 的签名、issuer、audience、有效期和 nonce，重新授权还校验原账号身份，避免覆盖成另一个账号。令牌临近到期时串行刷新并一起保存新的 access/refresh token，遵守平台给出的最早刷新时间。断开时尝试撤销远端 renewable session，并清除本地令牌；远端撤销未确认时明确提示。

模型调用使用 **官方 `https://api.openai.com/v1/responses`**。应用将既有 Chat Completions 格式转换为 Responses 输入，强制 `store:false`、`stream:true`，不发送该授权通道不支持的 temperature、max_output_tokens 等字段。只有收到 `response.completed` 才向写作模块报告成功，失败或不完整输出不会报告为成功。模型列表来自已授权账号，不能保证每个账号或套餐都拥有同一组模型和额度。

当前实现使用运行中后端的 `127.0.0.1` HTTP 回调，**适用于工作台与后端运行在同一台电脑的情况**。远程网站不自动复用此本机流程；需要另行实现适合部署方式的已注册 Web 客户端或受支持的宿主授权方案。

参考官方资料：

- [注册与登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
- [模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)
- [令牌及会话刷新](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)

## Muse：集成网页会话登录

Muse 部分参考 [muse2api](https://github.com/www222fff/muse2api) 的浏览器驱动方式，**直接集成在本项目中，不需要另行部署网关**。这不是 Muse 官方提供给第三方应用的 OAuth 模型授权。

1. 点击“登录 Muse（网页会话）”。
2. 后端在本机打开一个独立浏览器窗口，你本人在 Muse 网站完成登录；不会读取系统已有浏览器的账号资料。
3. 只有 Muse `/api/session` 确认会话已分配后，才加密保存本次独立会话并关闭窗口。
4. 回到工作台，账号显示“已连接”且有调用权限后，会自动加入下方 Agent 模型下拉列表。为写作、情节和世界观分别选择 Muse，或在账号卡片选择“全部 Agent”并点击“绑定到所选 Agent”。自动加入列表不会覆盖原有 Agent 选择；已登录账号在刷新页面或点击“刷新账号”时也会补入列表。

实际写作使用 Muse 网站当前提供的模型，不将其他平台模型名伪装为 Muse 模型。若列表仍只有默认项，先查看上方账号卡片是否显示“已连接”；仅在其他浏览器登录 Muse，不等于本项目已经保存隔离会话。

### Muse 用量与余额

账号卡片支持读取 Muse“设置→通用→使用情况”的真实用量：每周已用百分比及平台给出的重置说明，以及额外词元的剩余说明和有效期。保留平台原始单位；当平台只给出周用量百分比时，不推算周 token 总数，也不把额外词元与周额度合并。

打开账号设置时，首次或距上次读取超过 60 秒会读取一次；也可点击“刷新额度”。后端使用本项目已保存的隔离会话，仅打开设置读取用量，不提交聊天或点击升级/充值。结果附带更新时间；失败保留上次快照并显示错误，不把未知余额写成零。生成中同账号被占用时可稍后重试。重新登录成功会清除旧会话的额度快照。

浏览器仅接收用量白名单字段，Cookie 和会话仍保存在加密后端。此功能依赖 Muse 设置页结构，目前适配中文和英文设置入口；网页变化时会明确报告读取失败。

生成时在独立浏览器上下文中恢复该账号的 Muse 会话，打开空白会话后发送完整写作上下文，观察本次新回复并转换为应用原有的流式文本协议。不同账号不共享浏览器上下文，同一账号的请求串行处理。

不会自动点击 Muse 的外部操作批准卡片。遇到额外操作确认、会话失效、额度提示、网页输出重写或超时，返回明确错误；不把残缺结果当作完整替换文本。网页结构变化可能需要更新适配器。

登录窗口由运行后端的电脑打开，所以该方式也要求本机部署和可用的图形浏览器环境。纯服务器无桌面环境不能使用这个交互式登录入口。断开 Muse 仅删除本项目保存的会话，不会注销其他浏览器中的 Muse 账号。

## 凭据存储与权限

- 浏览器配置只保存 `accountId`、模型名及 Agent 分配；不接收或保存 OAuth access/refresh token、ID token 或 Muse Cookie。
- 后端凭据保存在 `NOVEL_DATA_DIR/credentials/`，Fernet 加密、原子写入。Windows 用当前系统用户的 DPAPI 保护主密钥；其他系统的密钥文件限制为当前用户读写，目录限制为当前用户访问。
- state、nonce、PKCE verifier 也保存在加密存储中，授权回调日志会去掉查询参数。
- Muse 浏览器与后端之间通过私有标准输入输出管道传递会话，不把会话放在进程参数中，也不返回给前端。
- 不应单独复制加密账号文件而遗失主密钥。Windows DPAPI 保护的凭据不能直接迁移给其他机器或系统用户；迁移作品后请重新登录平台账号。
- 工作台仍是**单用户、共享访问令牌模式**。拥有工作台访问令牌的人可以使用已连接账号，不是多租户账号隔离系统。

## 验证与限制

已完成后端 OAuth/账号测试、前端行为测试、模拟授权服务器下的真实浏览器 UI 回归，以及本地合成页面的 Muse 浏览器适配回归。覆盖身份签名、state 防重放、刷新令牌竞态、模型范围、代理转换、凭据脱敏和账号绑定。

ChatGPT 的真实在线授权和模型调用仍未纳入测试。Muse 已使用作者本人登录并保存的会话，只读验证设置页的周用量、重置说明和额外词元余额；没有为额度验证提交真实模型生成任务。另有隔离测试覆盖正常/耗尽/未知用量、读取失败保留快照、完整工作进程提交及凭据脱敏。上述测试不代表所有平台账号、套餐、区域或未来网页版本均可用。

2026-11-03 发布复核：ChatGPT 返回登录复用该账号已颁发的客户端 ID，并使用可选的邮箱 `login_hint`；不会为省略账号选择器而把 ID token 放进前端获得的授权地址。断开账号会取消尚未完成的授权等待，迟到回调不会重新保存令牌。Muse 登录使用独立尝试编号，生成、检查及额度读取与同账号登录互斥，已取消或被新登录替代的尝试不能恢复会话。上述竞态使用本地替身测试，不以真实账号付费调用作为回归。
