# 漫剧制作

在左侧进入“漫剧工坊”。制作台按作品保存全剧设定，按章节保存制作草稿和已应用分镜。它负责从正文到可编辑制作脚本的完整流程，输出的是制作资料；实际配音、图像、视频生成需要另接对应服务。

## 准备全剧设定

先选择有正文的章节，在“全剧设定”中配置视觉风格、画幅、每片段时长、镜头数、台词语速和改编原则。默认采用真人写实、竖屏、每段 15 秒 / 5 镜头，可以调整为动漫、3D 或自定义风格。每段可设 3–120 秒、1–12 镜头；这些是脚本目标，不代表目标视频平台支持同样参数。

人物记录外观和固定声线描述，场景记录空间锚点、光影和轴线，道具记录外观与状态。可同步小说人物、手动增删、锁定确认的设定，并关联素材库中已经上传的图片。锁定资料不会被模型提案覆盖；锁定不等于永久不可修改，用户可以主动解锁。

声线目前是供提示词和人工制作使用的文字描述，没有绑定 TTS 音色 ID。参考图用于人工查看和资料关联，当前文本 Agent 不会自动识图或将图片传给视频服务。

## 三个制作角色

| 顺序 | 角色 | 使用的现有模型配置 | 工作 |
| --- | --- | --- | --- |
| 1 | ComicScreenwriter（编剧） | 情节 / PlotAgent | 按原文段落拆剧情节点和制作片段，补充人物、场景、道具提案 |
| 2 | ComicDirector（导演） | 写作 / EditorAgent | 为每个片段安排景别、运镜、构图、时长、对白、光影和起止状态 |
| 3 | ComicContinuityReviewer（审阅） | 世界观 / LoreAgent | 检查当前片段及此前衔接资料，提出具体问题，不自动改写镜头 |

在“AI 引擎策略”中配置这三个角色。它们可以使用同一模型或不同模型，均经过现有账号 / API 适配层。生成包含多次模型调用；文本较长、片段较多时，调用次数与费用也会增加。

点击“生成制作草稿”后，后端按段落切分正文，为段落分配引用 ID。超长段落会进一步分块，所有非空正文都会进入拆解，不能仅靠分块保证语义完整。每次调用只处理一个原文块或制作片段，模型返回值会经过结构、引用、镜头数量和目标总时长检查，不合格结果不会替换已完成阶段。

每个成功阶段都会保存进度。中断后可“继续未完成任务”，复用已经完成的拆解、导演和审阅阶段。批量制作按章节顺序运行，并传递前面章节的制作设定；出现错误时停止，已完成草稿保留。停止任务会取消本地等待，供应商已经接收的请求可能仍然处理或计费。

## 编辑、应用与局部重做

生成结果首先进入“制作草稿”，已有的“已应用分镜”继续保留。可按片段查看和修改镜头，调整顺序、增删片段与镜头、编辑台词说话人及情绪、关联原文、设置声线参考和起止状态。

编剧提出的人物、场景与声线先保存在草稿快照中。在“全剧设定”点击“将草稿设定纳入全剧”，即可继续修改并锁定这些提案；编辑全剧资料后，点击“同步制作设定”更新当前草稿。同步会清除旧质检状态，需要重新核对。其他章节的已应用分镜仍保留原来的设定快照。

“重做当前片段”只调用该段的导演与辅助审阅，不覆盖其他片段或已应用分镜。片段中存在锁定镜头时需要先解锁；重做前方片段后，后续片段会收到复核连续性的提醒。

检查完成后点击“应用到本章”。空草稿、无效引用、已变化的正文、未同步的全剧设定或未保留的锁定应用镜头会阻止替换。应用只替换本章分镜，不修改正文。要替换已锁定的应用镜头，先主动“解锁已应用镜头”。

正文变化后原分镜仍可查看、导出，但旧草稿不能直接应用，需要重新制作。生成期间切换作品、删除章节或修改正文 / 制作设定时，会停止或拒绝迟到结果。

## 连续性与质检

全剧设定保存到作品的 `comicProduction`；章节中的 `comicDraft` 保存进度，`comicPlan` 保存已应用的制作元数据，`comicShots` 保存镜头。章节结果包含原文 SHA-256，只有正文仍一致、状态为完成的上一章节，才可提供结束状态。未完成或正文已变化的制作状态不进入连续性检索。

规则检查涵盖引用有效性、遗漏的原文关联、人物 / 场景引用、台词说话人、镜头数量、目标时长和按字数估算的台词容量。忠实模式还检查台词能否在关联原文中找到。原文引用覆盖不等于剧情没有遗漏，台词语速也只是估算。

“当前片段 AI 质检”可重新审阅选中的片段。修改分镜或同步设定后，原有意见可能过期，界面会提示重新质检。模型意见辅助人工检查，不能保证故事语义、轴线、声线或最终视频零穿帮。

## 导出制作资料

| 格式 | 内容与用途 |
| --- | --- |
| TXT | 按片段组织的中文视频制作提示词，或英文图像提示词 |
| JSON | 包含设定、原文引用、镜头与审阅状态的结构化资料；目前没有对应的导入入口 |
| CSV | 可在表格软件中整理的分镜表，包含时长、画面、台词和中英文提示词 |
| SRT | 根据镜头时长排列的字幕；同镜头多条台词均分时段，尚未按实际配音对齐 |

“即梦 / Seedance”和“通用”导出中文制作文本；“英文图像提示词”使用英文画面字段和画幅参数。当前未调用这些平台的生成接口，不包含未经验证的步数、强度等专属参数。SRT、声线描述和参考图关联均不代表已经生成音频或视频。

## 旧数据与升级

旧的画面 / 台词 / 提示词分镜可以继续查看与导出，不会在打开页面时被自动重写。创建编辑草稿后，可补充时长、场景和原文引用；确认应用前仍保留原数据。

旧 SQLite 数据库首次升级时，会先用 SQLite 备份 API 在数据目录的 `backups/` 留存备份，再添加制作设定字段。分镜进度更新不会挤占正文最近 20 个历史版本。备份和用户作品不会进入开源包；完整备份方式见[保存与备份](data-and-backups.md)。
