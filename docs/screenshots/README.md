## 重新生成

在项目根目录安装 Python、npm 与 Playwright 浏览器依赖后运行：

```bash
npm run docs:screenshots
```

脚本默认使用项目 `.venv` 内的 Python，也可通过 `PYTHON` 指定解释器。默认前端端口为 16273、后端端口为 18200，可通过 `NOVEL_SCREENSHOT_UI_PORT` 和 `NOVEL_SCREENSHOT_API_PORT` 改写。

脚本会屏蔽外部网络和模型/账号端点，在临时数据目录中创建虚构作品，并在退出时关闭自己启动的服务和清理临时数据。不要将真实作品或账号添加到截图脚本中。
